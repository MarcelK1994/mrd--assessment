# MRD Assessment

A small TypeScript full-stack catalogue search application built with Express and a framework-free frontend.

For video breakdown by author, see video link: https://drive.google.com/file/d/1wwjRp2NweHWsPhNlmc2UGTCoEiCG3ZBb/view?usp=sharing

## Features

- Search by name, category, or description
- Filter by category
- Sort by price ascending or descending
- Responsive UI with loading, empty and error states
- Node.js + Express API with TypeScript on the server

## Run locally

1. Install dependencies:
   npm install
2. Start the dev server:
   npm run dev
3. Open http://localhost:3000

## Test

npm test
